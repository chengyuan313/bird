# 四川 V7 D5 真人试玩方案（待执行）

本方案用于评估未发布的 D5 内容构造候选是否值得替换现有题库。离线实验的非预言策略在独立验证与审计种子上表现较好，但这些数字不是人的通关率。本文件只规定试玩方法和通过门槛；截至写作时没有招募玩家，也没有真人结果。

## 冻结版本与隔离

试玩前将五局候选各自的实验版本、`puzzleId`、`boardHash`、90 字词语配额、胜利证书、来源审查结果记录到只读清单，并对每局完成一次引擎回放。首次玩家进入后，整个样本期间不更换棋盘、词表、提示文案或计分规则。研究人员不得按早期试玩结果挑选另一候选；任何改动都开启新版本和新一轮样本。

候选仅在独立内测入口和独立浏览器存储命名空间运行，不覆盖正式 `regionalV7Bank.json`、现有谜题 ID、V6/全国谜题或 `bird.regions.v1` 进度。试玩记录不计入正式收藏、解锁和旧版统计。撤销、提示和十格字槽的行为应与拟发布的四川 V7 交互一致。若将来决定发布新 D5，先单独设计旧题重玩及完成记录并存或显式迁移，再发布新版本身份；本次试玩本身不做迁移。

## 招募与安排

- 招募已实际完成 D4 的玩家，每局至少 20 名不同的同意参与者；同一个人可以玩多局，但不能在同一局被重复计数。记录是否已玩过其他候选局，避免把熟悉度当作首玩表现。
- 将五局出场顺序轮换，让每局都有首场、居中和末场玩家；不要让 D5 第五局总承受疲劳影响。每局 320px 与 390px 宽度各至少 10 名参与者，并记录设备、浏览器和输入方式。至少部分场次使用真实触屏。
- 先给所有人相同的 D5 规则说明：亮字可取、十格字槽、局内鸟名与剩余次数、撤销和重试。研究人员不解释具体解法，不透露证书、隐藏字或预期取字顺序。局内常驻鸟名清单属于标准界面，不算额外提示。
- 完成每局后，单独询问鸟名重复是否影响趣味性，以及相对已通关的 D4 是更容易、相近还是更困难；逐局记录，不用离线策略胜率推断玩家主观难度。
- 参与者可随时停止。单局最多观察三次尝试或 20 分钟；重试开启新尝试，连续撤销仍属于当前尝试。到上限未完成、主动退出或技术中断都保留在分母，并分别标记原因。

## 同意与最小记录

开始前说明这是未发布原型、可能较难，可随时退出；告知记录字段、保存期限和联系人，取得明确同意。默认只在研究设备本地记录匿名参与者编号、候选版本与局号、屏宽、开始/结束时间、每次尝试的胜败、是否撤销、撤销次数、满槽失败、重试次数、离开原因及观察到的误点。不要采集姓名、账号、精准位置、原始点击轨迹或完整浏览器存档。录屏、声音和逐步操作日志需要另行同意；拒绝不影响参与。导出仅使用汇总表，完成审查后删除原始记录。

## 指标、分母与门槛

每局的分母是该局**开始游玩**的不同合格参与者，至少 20 人；中途退出、满槽失败、超时和技术中断都不从分母中剔除，技术中断另报以便判断是否需要重测。跨五局汇总时使用 100 个“参与者×局”首次进入样本，注明同一人可能贡献多个局。

| 指标 | 计算方式 | 原型推进门槛 |
| --- | --- | --- |
| 首试无辅助通关 | 第一次尝试中未使用撤销或额外研究员提示即完成的人数 ÷ 该局开始人数。标准局内鸟名/配额不算额外提示。 | 五局合计 ≥30%；任何单局 ≥20%。 |
| 三次内可恢复通关 | 第 1–3 次尝试内完成的人数 ÷ 该局开始人数；允许使用局内撤销，且必须单列未用/使用撤销人数。 | 五局合计 ≥60%；任何单局 ≥50%。 |
| 完成用时 | 从第一次进入该局到第一次完成的累计实际游玩时间，含重试；明确暂停超过两分钟的时段并扣除。只对完成者计算中位数，未完成者人数另报。 | 每局完成者中位数 ≤15 分钟。 |
| 误点与死局 | 每局记录满十槽且无鸟可拼、遮挡字误点、横滑误触、撤销后无法继续的次数与受影响人数。 | 不设用自动胜率替代的阈值；出现无法操作或进度损坏即停测修复。 |

所有比例同时报告分子、分母、设备分层和是否使用撤销。不得只报告完成者的平均用时、删掉退出者或把五局重复参与者称为 100 名独立玩家。达到这些门槛仅表示可以继续产品评估，不表示五级难度或商业上线已经验收。

## 移动端观察与停止条件

在 320px 和 390px 真实渲染宽度下观察：页面本身没有横向溢出；90 字棋盘可在容器内横滑；露出字在滑动前后能准确点按，遮挡字不能触发；十槽、五六字鸟名、剩余配额及撤销入口始终可读。记录字块可见面积和实际命中区域，不能只以 CSS 的 48px 宽度判断触控足够。若同一局出现连续两名玩家因横滑/命中错误而无法完成正常操作，暂停该局，修复后用新版本重新测试。

出现旧存档被改写、研究记录未经同意外传、胜利证书与真实引擎不符、无法撤销满槽失败或任何不可恢复的进度错误时，立即停止全部试玩并回到当前正式题库。若某局首批 10 名玩家在三次尝试内全部未完成，也暂停该局做问题复核；该批结果保留并公开报告，不能删除后继续凑达标样本。未达到上述门槛的候选继续保持实验状态，不替换已发布题库。

## 交付

试玩结束应交付冻结版本清单、招募与同意记录的匿名汇总、逐局逐设备指标、失败/退出原因、观察到的操作问题、是否达到每项门槛，以及明确的发布或继续改版建议。若任何阶段没有足够真人样本，结果只能写“尚未真人验证”。
