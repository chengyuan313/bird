# 《字里有鸟》微信小游戏固定屏 PRD

状态：产品验收草案。目标平台是**微信小游戏**；当前 Vite 网页是玩法原型，不能称为已交付的微信小游戏。迁移时保留四川 V7 的物种、题目身份、配额、得分与历史进度语义。本文件规定游戏场景布局，不改现有题库或存档。

## 场景与一屏规则

地区选择、四川主页、100 鸟图鉴、本关完整词表、设置与来源致谢分别作为非对局场景或暂停浮层。进入对局后，舞台固定在设备可用区域内：页面整体不得纵向或横向滚动，顶部和底部依微信运行环境的实际安全区留白，不用写死状态栏高度。结果、失败、词表浮层覆盖舞台并保留当前棋盘状态，关闭后回到同一局面。

对局同屏从上到下只保留五层，优先级固定：①地区、D 级、局数、剩余字与返回；②棋盘；③十格字槽与容量警示；④当前可拼鸟名的主操作；⑤始终可见的撤销、词表与重试入口。完整的 20–40 个鸟名及每词配额放在“本关词表”暂停浮层，100 鸟资料只在四川主页图鉴中浏览；对局舞台不铺长列表。主操作区只显示现在能拼的词与一个选中的目标词，多个可拼词可在局部横向切换，不推动整个舞台。

## 两种最低验收视口

下表是安全区扣除后的**弹性分配目标**，不是固定像素坐标。小屏优先保证字槽、组词和撤销能同时看见；棋盘只在自己的视窗内平移或放大，绝不把 90 字板整体缩到字块难以点击。

| 视口 | 对局舞台要求 | 棋盘交互区 | 底部固定操作区 |
| --- | --- | --- | --- |
| 320×568 | 扣除真实安全区后全部关键操作同屏；HUD 压缩为单行，字号仍可读。 | 至少约 200px 高的局部窗口；允许棋盘内部横向、纵向平移和局部放大。 | 十格字槽、当前可拼词、撤销/词表/重试常驻，不因键盘或浮层被推出屏外。 |
| 390×844 | 顶部信息可展开但不增加页面滚动。 | 优先展示完整或接近完整的 350×326 棋盘；需要时仍可局部平移。 | 与小屏相同的操作顺序和位置，增加信息留白，不改变规则。 |

游戏舞台在安全区、屏幕旋转、微信顶部控件变化后重新排布；不采用 CSS 网页长页面滚动作为游戏交互。棋盘内部移动时，字槽和撤销保持静止。10 个槽位主要用于展示，不强迫每槽都有 44px 宽；所有**可操作**按钮、鸟名选项、导航和浮层关闭控件的有效点击区域至少 44×44 CSS 像素。

90 字棋盘的重叠字块不能仅凭外框宽 48px 宣称可点击。露出字必须有至少 44×44 的有效命中区域；若叠层遮挡做不到，点按密集区域先打开局部放大/候选选择层，玩家再点一个无遮挡的 44×44 目标。被遮挡字不可取且需有明确视觉区别。棋盘移动、放大和选字不得误触“返回”或组词；拖动结束不得自动取字。

## 核心操作与状态

- 新手首局在同一屏用三步短提示说明“点亮字→进入十格→点鸟名组词”，提示不遮住首个可取字或撤销。后续随时从词表浮层查看规则。
- 字槽显示当前占用和 `x/10`；达到 7 格时仅提示“优先拼词或撤销”，不宣称某个字安全，也不读取胜利证书推荐路线。没有可拼词时主操作区清楚说明还缺字；可拼时每个按钮显示准确鸟名和得分。
- 撤销始终在固定操作区，支持多步恢复取字、组词及满槽失败；每步恢复棋盘、槽、配额、分数与本局临时发现。胜利为不可撤销的结算点。失败遮罩必须留有“撤销上一步”和“重试本局”，不能迫使玩家退出。
- “本关词表”浮层可搜索或按剩余次数筛选，展示本局名称、剩余 occurrence 和规则说明；打开它暂停操作而不重开谜题。四川 100 鸟图鉴在非对局场景按 D1–D5、发现状态、地方重点筛选，保留逐条来源入口和“精选 100 种，不是全省总数”说明。

## 验收门槛

在 320×568 与 390×844 的微信小游戏实际运行环境各完成 D1 首局和 D5 一局的人工操作检查，并覆盖有安全区差异的两台真实触屏设备。必须同时满足：对局外层无滚动和裁切；棋盘内部可到达所有 90 字位置；露出字能准确选取、遮挡字无法选取；十格、当前可拼词、撤销始终同屏；五六字鸟名与按钮文字不截断；打开/关闭词表后棋盘位置、槽与进度不变；满槽失败后可连续撤销；完成后历史发现与谜题完成记录保留。录制完整操作路径和两种视口截图，记录误触与有效命中区域。

发布前还需通过现有证书、配额、来源与迁移测试，并在真实微信小游戏构建中验证加载、切后台恢复和存储。离线策略胜率与网页截图均不能替代真实平台触控和真人难度测试；当前 D5 词内容实验只是待内测候选，正式题库及旧进度保持不变。
