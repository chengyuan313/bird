# D5 词内容升级离线实验（未发布真人原型候选）

日期：2026-10-15。运行 `node tools/runRegionalV7ContentUpgrade.mjs`；子进程 90 秒硬限。代码、实验测试与报告独立于正式题库。**没有**改动已发布 `regionalV7Bank.json`、原生成器、UI、存档或历史谜题 ID。

## 事先固定的方案

词只来自已核对的[四川省鸟类名录 2020 年版](https://html.rhhz.net/scdwzz/html/61796.htm)对应的 V7 四川 100 种，逐 occurrence 校验 species ID、省来源、原中文名与学名。每局 90 个汉字、十槽、≥20 个不同词、每词≤2 次、≥2 个有四川省记录的编辑精选词、5–6 字词 occurrence 4–8 个。每局须出现本级新鸟固定四种；五局并集覆盖 D5 的 20 个新鸟。所有候选有新实验身份和板哈希、真实引擎回放证书，见证槽占用≤10。不能用别名凑数，也不能放宽条件来获取高胜率。

每局至多 20 候选，A/B 各 10。A 低共享字冲突填充，采用词片段交错布局；B 优先短词、早期可完成与不同阻挡分支，采用分支式布局。两法都保留原 90 位置及阻挡关系。训练仅用 trialIndex **101–105**，验证 **201–205**，审计 **301–305**，与旧实验 0–9 完全不重叠。预先冻结的两种可见信息策略为 `word-seeking`、`word-cluster`；每次≤180前进动作+20单步撤销，不读证书、隐藏字或训练成绩。只根据训练胜局选板；锁板后一次性读验证。验证须≥30/50、五局各≥2/10且优于原板，才运行未见审计；审计也须同门槛，不得调参回选。

## 未解决的产品问题

词表大量依赖重复的 2 字鸟名，虽满足每词≤2，可能使 D5 人工感知上比 D4 更轻松、重复感更强；并非五级难度已校准。部分物种仍保留源名的暂定分类标记，尚待专家复核。必须由已经通关 D4 的玩家对每局至少 20 人测试：首次无辅助通关≥30%，三次内含撤销通关≥60%，中位完成≤15 分钟，且每局完成率≥20%；这些是原型评估门槛而非商业上线承诺。未做真人测试前，候选继续留在离线实验，不写入正式题库。
