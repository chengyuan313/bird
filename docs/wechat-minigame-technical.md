# 微信小游戏 Canvas 技术切片

2026-10-30 更新：当前交付范围、存储契约和真机验收见 [微信内测说明](wechat-internal-test.md) 和 `src/wechat/ui/HANDOFF_STATUS.md`。

这是独立于 Vite 网页的四川微信内测版，尚未发布到微信。它复用当前四川 V7 正式题库与纯游戏引擎，不改网页版进度。启动进入四川首页，可选择 D1–D5 共 25 局，触摸取字、组词、撤销、重试、下一局，并浏览 100 鸟手册和来源、设置触感及动态效果、恢复进行中对局。真人难度校准及真机验收仍未完成。

## 构建与导入

无需 AppID 的浏览器界面预览：启动 Vite 后打开 `/bird/?preview=wechat`（本机默认 `http://localhost:5173/bird/?preview=wechat`）。这个入口直接挂载同一个 `WechatBirdStage` Canvas 舞台，可切换 320×568 / 390×844，模拟安全区、鼠标与触屏操作；它不使用网页版的长页面对局 UI。浏览器预览仅用于快速评审布局和操作，不能替代微信运行时或真机验收。

在仓库根目录使用现有依赖运行 `node tools/buildWechat.mjs`（或 `pnpm run build:wechat`）。产物是忽略版本控制的 `dist-wechat/game.js` 与 `dist-wechat/game.json`；没有 WXML、DOM、AppID、远程资源、源凭据。构建走 Vite 的内联 `configFile: false`，避免 Windows sandbox 的 Vite 配置打包权限问题；没有新增全局包。将 `dist-wechat` 作为“小程序/小游戏”项目目录导入微信开发者工具，并由仓库所有者在开发者工具中提供自己的小游戏 AppID。**不能以网页 URL 或本地 VM 烟测代替微信开发者工具/真机验收。**

入口 `src/wechat/game.ts` 使用 Canvas、触摸、安全区、本地存储、前后台事件与可选剪贴板。舞台接收这些能力的适配接口，可在浏览器 Canvas 测试壳中复用。`bird.wechat.v1` 保留完成与发现记录，另用版本化键保存偏好及合法操作续玩。胜利结算一次且不可撤销；失败可以使用原剩余次数撤销。存储不可用时仍可游玩，并明确提示无法保证跨启动进度。

## 当前固定屏交互

- 320×568 / 390×844 按运行时 safeArea 分配 HUD、局部棋盘、十槽、组词和固定按钮；若有效安全高度小于 344px 则显式拒绝，以免棋盘与控件重叠。整个舞台不使用网页滚动。
- 棋盘固定、不可拖动，字块触控目标至少 44×44。D1/D2 的紧密牌堆沿用已验收尺寸，D3–D5 保持原题库。重叠露出字进入 44px 候选层并可双向分页；遮挡字不进入候选层，点按遮挡牌不会穿透到下层。
- 同时多个可拼词有“全部可拼 n”入口；组词列表按弹层真实高度分页，双向切换且每行间隔 48px。词表也按高度分页。
- 结算可下一局或返回首页；首页展示完成/观察进度、继续游戏、关卡、手册及设置。最小安全高度下各页仍分页，内测关卡全部开放。

## 自动验证与尚缺验收

`tests/wechat-stage.test.ts` 保留固定棋盘、露出/遮挡、候选分页、多词选择、最小安全区、撤销、25 局导航和证书点击回放。`tests/wechat-exploration.test.ts` 覆盖首页至手册、来源、引导、设置、续玩与换关确认、25 局检查点重建和存储失败。无 DOM VM 烟测检查原生入口的首页、引导、真实触摸回调、前后台检查点、手册及冷重启。模拟点击不能证明真机命中率、字体、性能和微信存储兼容；需要在开发者工具及两台真实触屏设备上验收。

参考微信官方小游戏样例的 `game.js` / `game.json` 工程结构：[wechat-miniprogram/minigame-demo](https://github.com/wechat-miniprogram/minigame-demo)。
