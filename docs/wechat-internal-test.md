# 四川微信内测版：实现与验收

2026-10-30。本轮实现完整的本地试玩闭环，沿用四川 25 个已认证谜题、100 个来源记录和验收过的固定棋盘。微信真机状态单独记录，不把浏览器和无 DOM 烟测写成真机通过。

## 当前流程

启动进入四川首页，显示完成局数与已观察物种数。无续玩记录时，“开始探索”推荐第一个未完成谜题；有记录则显示“继续”。关卡页面为内测全部开放，逐局标记完成，不表示难度已经校准。替换已有操作的对局前须确认，取消保持原局。首次游玩显示可跳过的三步说明，设置里可以再次查看。

观察手册分页展示全部 100 个名称（含待观察），按初次引入的 D 级和已观察状态筛选。详情使用现有中文名、学名、清单行号、已有生境证据和来源链接，不添加无出处图片或声音。首次发现只有通关才写入长期手册，撤销、失败和重试不会提前解锁。

所有页面固定在安全区内；列表按可用高度分页，操作目标至少 44×44。对局内不能拖动。每局 3 次撤销，次数角标显示真实剩余次数；未接入激励广告。设置提供触感和取字动态效果开关，跨启动保持。浏览器与微信进度分别保存在各自本机，不做云同步。

## 存储契约

- `bird.wechat.v1`：原有完成和物种发现记录，以及已发布的 D1/D2 完成身份迁移，原样保留。
- `bird.wechat.preferences.v1`：触感、动态效果、是否看过引导。
- `bird.wechat.session.v1`：规则/词表版本、谜题 ID、精确板面哈希、级别/局号、合法操作记录和剩余撤销次数。最多 180 步。

恢复时从当前不可变题目输入开始，由引擎逐步回放操作，重建棋盘、字槽、分数、配额、临时发现及撤销历史；不信任存档中的序列化引擎状态。错误身份、版本、哈希、非法动作、重复取字、胜利后的多余动作和错误次数拒绝恢复，不静默换成另一道题。旧完成记录不因续玩失效而删除。

每次合法动作、撤销和切后台写检查点。通关先写完成与发现，再清除续玩记录；存储失败显示警告并保留最后可用检查点。原生使用 `wx.onHide/onShow`，浏览器预览对应 visibility/pagehide。失败局可重新启动后继续并使用原剩余次数撤销。来源链接只有环境反馈复制成功才提示成功。

## 导入和试玩

1. 在仓库根目录运行 `node tools/buildWechat.mjs`，输出 `dist-wechat`。
2. 在微信开发者工具导入**小游戏**，目录选择 `dist-wechat`，由所有者填写自己的小游戏 AppID。无需把 AppID 或账号提交到仓库。
3. 浏览器入口为 `/bird/?preview=wechat`；附加 `capture=1&device=compact` 或 `device=regular` 可隐藏预览工具栏。
4. `tier/stage` 参数是显式重开指定局的调试入口。测试退出续玩时移除它们。
5. 构建后运行 `node tools/smokeWechatBundle.mjs`，在无 DOM 环境检查首页、引导、取字、前后台检查点与图鉴。

## 真人试玩与后续

先用小批玩家发现操作问题，再按 `regional-v7-human-playtest.md` 校准难度。记录每局开始人数、首试通过数、三次内通过数、退出/技术中断、用时、撤销和误触；退出者不从分母删除。该微信内测版未接入自动统计，采用明确同意后的人工匿名记录。算法胜率和证书回放不代替真人数据。

后续为真机性能与恢复实测、真人难度校准、完整视觉动效验收及激励广告。素材商业发布权仍由提供方确认；未打包宋体字库。本轮没有修改题库、游戏引擎、评分或几何。
