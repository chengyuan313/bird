# V7.5 四川省优先内容与题库审计

## 范围与来源

V7.5 在四川上线一套独立于旧版全国 103 词表的省级物种、地区记录和可拼名称模型。`data/regional-v7-sichuan.json` 的 100 个四川入选物种逐条保留中文名、学名和清单序号，来源为[《四川省鸟类名录的修订与更新》](https://html.rhhz.net/scdwzz/html/61796.htm)（2020）。**100 是本游戏的精选数，并非四川鸟类总数。**原文报告四川 757 种；此处没有复制整份清单或媒体素材。23 个名称及学名均与旧目录一致的条目复用原物种 ID；77 个条目使用新的 `species:<scientific-name-slug>` ID。原始来源名称被保存为暂定版本，尚未完成现行分类系统的逐一核对，不应作为 2026 年权威分类表引用。别名和同义分类不增加物种数量。

地区重点是编辑性选择，不等于四川特有。21 个标记物种在省级清单有记录，其中独立生境资料目前只核实两例：[若尔盖湿地与黑颈鹤](https://www.forestry.gov.cn/c/www/sdfc/98735.jhtml)、[马鞍山四川山鹧鸪繁殖生境调查](https://cjournal.hep.com.cn/1001-8395/CN/10.3969/j.issn.1001-8395.2026.04.009)。其余重点物种只展示清单来源，不编写无出处的地点故事。科学名称、中文名称及省级出现的进一步审校仍是公开发布前的编辑任务。

## 模型、规则与题库

- `regionalV7Data.ts` 区分物种主表、`CN-SC` 地区出现证据、可拼词及五个累计难度池。每级新引入 20 种，累计为 20/40/60/80/100；一局只允许该局词语配额中的名称，不把全部地区词表全局放开。
- 中文名按 Unicode 字符拆分并限定 2–6 个汉字。旧有 2/3/4 字评分保持不变；新增 5 字 120 分、6 字 180 分。十格字槽和逐词配额保持不变。
- 离线生成器以种子、难度、版本、词语配额与板面哈希生成独立 ID；每级五局，共 25 局。棋盘分别有 22/33/45/60/90 字；22/33 复用旧坐标，45/60 从已验证 90 字 Piachan 坐标取子图，90 使用完整坐标，不改历史棋盘。每局至少安排该级四种新引入鸟名，完整五局覆盖新增 20 种。
- 每局有完整的引擎回放胜利证书及最大见证字槽占用记录。`independentSearchStatus=NOT_RUN`：工程化胜利路线不等于独立搜索，也不能证明玩家任意操作都可赢。无法满足精确字数或词配额时，生成器在 200 次有界尝试后明确失败，不偷偷替换谜题。
- 25 局的固定非预言基线（能拼则选 ID 最小的词，否则取 ID 最小的可取字）均胜利；这仅是一个策略的诊断，且取字次序与题目构造相关，**不能据此宣称人类难度已校准**。另用每局 10 次固定种子随机合法操作、不读取胜利见证：D1 44/50、D2 3/50、D3–D5 各 0/50 胜利，未出现预算未决状态。随机操作本身不等于真实玩家策略；结果提示 D2 以后失误风险显著，必须真人试玩。引擎证书最大字槽占用分级范围为 D1 3–4、D2 4–6、D3 4–5、D4 4–6、D5 6；初始可取字分别为 11/11/21/20/19。仍需独立的更合理策略及真人试玩记录，以调整共享字、遮挡和不可逆失误风险。

运行 `npm run generate:regional-v7` 可重新生成版本化 JSON 题库；在 Codex Windows 沙箱中，可用已有 Node 运行 `node tools/runRegionalV7Bank.mjs`。不要用该命令改写历史题库。

## 覆盖与兼容

四川：100/100，V7 完整五级。北京 10/100、辽宁 22/100、广东 22/100、云南 19/100，均保留并明确标为历史预览；其余 29 个省级地区为 0/100，未标为 V7 完成。当前 34 地区合计 173 个已关联物种名额，距 3400 个目标还差 3227 个地区—物种关联。**不能将四川物种未经核实直接复制到别省。**下一批应先为北京、辽宁、广东、云南各找当地清单并逐条整理、核验；再分批推进其他 29 地区。

旧版全国 103 词条、105 个认证谜题、15 个实验谜题、V6 省级谜题 ID/哈希均未迁移或重写。地方进度保留同一个本地存储键与原记录，仅将新写入记录的内容版本标为 V7.5。四川旧版两关仍可重玩，且不计入新的 25 局；此前发现和统计数据不应被清除。

## 商业化前尚需解决

内容缺口（另外 33 地区未完成）、单条地区特色生境证据、暂定分类、长期身份迁移策略、真人难度校准、可商业使用的鸟类图像/声音授权，以及全设备可访问性复核。当前没有加入第三方图像或声音，也不将清单事实数据附带任何媒体许可主张。四川 V7 是可玩且可核查的省级样板，并非 34 省的商业化完成品。
